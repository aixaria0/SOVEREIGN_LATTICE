Sovereign Lattice

Architecting formally verified autonomy, non-blocking asynchronous consensus, and threshold cryptography at the edge.

🌐 1. Network Ingestion

src/network.rs spins up a non-blocking TCP socket listener via Tokio to ingest live cryptographic payload events from external network nodes in real time.

🛡️ 2. Cryptographic Core

Every transaction block requires a mathematically validated aggregate signature checked against the master group public key, discarding malicious actors instantly.

⏱️ 3. Async State Loop

The core daemon src/main.rs monitors progress timers. If a leader node stalls, it automatically coordinates view-change protocols.

📊 System Specifications
